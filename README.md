# imre-skills

PUDA machine skills for IMRE.

Before a physical IMRE workflow whose safety or correctness depends on visible setup, load the central `puda-machine-vision-validation` skill, confirm `puda env current` is `imre`, and use an IMRE-scoped machine/camera profile. Never reuse BEARS or NTU camera calibration, workspace geometry, credentials, or prior confirmations.
